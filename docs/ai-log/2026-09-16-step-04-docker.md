# Шаг 04, часть 3 — сборка, nginx и Docker

Дата: 2026-09-16

Бюджет клиента измерен и закреплён проверкой `npm run check:size` (166.73 kB gzip из 200 —
оптимизировать не понадобилось), стек `docker compose` из nginx со статикой и мок-сервера
поднимается с нуля без `.env`. `.env` сведён в один корневой файл.

## Изменения

- `scripts/size` (новый пакет `@scripts/size`) — `check.ts` и порог `size.config.json`;
  корневой скрипт `check:size`, workspace добавлен в `package-lock.json`.
- `docker-compose.yml`, `.dockerignore`, `.env.example` в корне; `apps/web/Dockerfile`,
  `apps/web/nginx/default.conf`, `apps/mock-api/Dockerfile`.
- `apps/mock-api/src/server.ts` — `STREAM_INTERVAL_MS` из окружения, dotenv читает корневой
  `.env`. Удалены `apps/mock-api/.env.example` и локальный `apps/mock-api/.env`.
- `README.md` — раздел «Запуск в Docker», решения по сборке и выкладке, трактовки, бюджет с
  разбивкой; счётчики (387 тестов, 285 мутаций) и таблицы мутаций из полного прогона.

## Решения

**Измерить, потом решать** → `vite build`: один чанк 535.00 kB, gzip 168.70 kB по отчёту Vite
(166.73 kB при gzip -9). Состав — `source-map-explorer` по сборке с source map во временный
каталог: react-dom 202 kB, react-router 90, zod 81, `@entities/org-tree` 39, styled-components
со stylis 28, redux-saga 15. По source map: исходников мока, тестов и dev-сборок библиотек нет,
каждый пакет в одном экземпляре. Бюджет соблюдён — ничего не оптимизировалось, разделение кода
из шага 01 не пересматривалось. `rollup-plugin-visualizer` не ставился: разовый анализ через
`npx` не меняет зависимости.

**`check:size` — отдельный пакет в `scripts/`** → как `@scripts/mutation`: lint и typecheck
через `lerna run`. Меряет gzip -9 — тот же уровень, которым сборка предсжимается для nginx;
килобайт 1000 байт, как у Vite. Сборку не запускает: проверка читает готовый `dist`. Без
тестов и мутаций — как и раннер мутаций; падение при превышении проверено вручную порогом 150.

**`gzip_static` плюс `gzip on`** → статика неизменяема: сжать один раз максимальным уровнем
дешевле, чем сжимать на каждый запрос, и по сети уходит измеренное. Сжатие на лету оставлено
для JSON из API (`gzip_proxied any`, уровень 5, от 1024 байт). Отброшено: только `gzip on` —
CPU на каждый запрос бандла и меньшая степень; только `gzip_static` — JSON API без сжатия.
`text/event-stream` в `gzip_types` нет.

**Кэш** → `/assets/` — год и `immutable`, `try_files $uri =404`; остальное — `no-cache`.
Сначала `add_header` стоял с `always`, и 404 отсутствующего чанка получал `immutable` на год —
замечено на `curl -I`, `always` убран.

**SSE: заголовки прокси на уровне `server`** → `proxy_set_header` внутри `location` отменил бы
наследование, а потоку нужен `Connection ""`; `proxy_http_version 1.1` и пустой `Connection`
заданы для всего `/api`.

**Порты** → `PORT_WEB=8080`, `PORT_API=3002` — порты на хосте; 3001 и 5173 заняты
`npm run dev`, умолчания не должны с ним конфликтовать. Внутри сети api слушает 3001, nginx
ходит на `api:3001`, шаблонизация конфига nginx не нужна.

**api: `node --import tsx`, `init: true`** → один процесс node без дочернего процесса tsx CLI;
tini завершает его по SIGTERM сразу, а не по SIGKILL через 10 с. Healthcheck — busybox `wget
--spider` по `/api/org-tree`: проверяет и HTTP, и данные; `start_interval: 1s` — web стартует
через секунды, а не через `interval`.

**Манифесты до `npm ci` — `COPY --parents` по маскам workspaces** → явный список из 13 путей
ломался бы на новом пакете; маски совпадают с `workspaces` корневого `package.json`. Web
ставит все зависимости (сборке нужны пакеты слоёв и typecheck), api — `npm ci --workspace
@app/mock-api --include-workspace-root=false`.

**Один `.env` в корне** (указание человека: ключ должен храниться в одном месте) → раньше
`npm run dev` читал `apps/mock-api/.env`, а compose — корневой `.env`. Dotenv теперь читает
корневой файл; в контейнере его нет (`.dockerignore`), переменные приходят из `environment`
compose, dotenv существующие не перезаписывает. Значение ключа во всех трёх файлах совпадало
(сравнение по sha256 без вывода), перенос ничего не потерял.

## Отступления от инструкции

- **Генерация патчей в контейнере стартует сама** (решение человека: «мок сам будет всё
  делать»), ТЗ требовало включения дев-ручкой. Одноразовый сервис `stream-autostart` ждёт
  healthcheck api, шлёт `POST /api/dev/stream/start` и завершается; `STREAM_AUTOSTART=false`
  выключает. Сначала сделан профилем compose (`COMPOSE_PROFILES=live`), но умолчание профиля из
  `.env.example` без `.env` не действует — профиль заменён переменной. Критерий «`down && up` —
  данные детерминированы» теперь выполняется для стартовых данных; целиком — с
  `STREAM_AUTOSTART=false`.
- **Код мок-сервера изменён** (`server.ts`), хотя ТЗ разрешало правки кода только ради
  бюджета: `STREAM_INTERVAL_MS` сервер из окружения не читал, а ТЗ требует его в `.env`;
  путь dotenv — по указанию человека.
- **«Stub-режим» и «stub-образец даёт структурный фильтр без ключа»** — заглушки нет (решение
  человека в части 2). Без ключа проверен текстовый ответ, с ключом — структурный.
- **«Без `proxy_buffering off` события не доходят»** — в одиночку не воспроизвелось: nginx 1.30.5
  с буферизацией (и `proxy_ignore_headers X-Accel-Buffering`) доставил `hello` и патч сразу.
  Воспроизвелось вместе со сжатием потока: за 8 с ни одного события при живом соединении.
  Сжатие потока при `proxy_buffering off` события тоже не задержало. Директива оставлена.
- **`apps/mock-api/.env.example` с рабочим ключом удалён** — ключ в одном месте; корневой
  `.env.example` по ТЗ с пустым ключом. Проверка живого режима проверяющим теперь требует
  своего ключа.
- **Браузерная проверка «патчи доезжают и подсвечиваются»** агентом не выполнялась — браузера
  у агента нет. Проверено `curl -N` через nginx: патчи от `stream/start` доходят раз в 5 с.
  Подсветку в браузере должен проверить человек.
- **Полный прогон мутаций шёл при запущенных dev-серверах человека** (5173, 3001): их не
  останавливали по указанию человека. Docker-стек на время прогона остановлен.

## Известные проблемы

- `docker compose up -d --force-recreate api` (только api) генерацию заново не включает:
  `stream-autostart` перезапускается, когда compose обновляет api в общем `up -d`.
- Образ api — 285 MB: `npm ci --workspace @app/mock-api` ставит и его devDependencies (`tsx`
  нужен в рантайме, вместе с ним приезжает `vitest`). Критерием не было, не оптимизировалось.
