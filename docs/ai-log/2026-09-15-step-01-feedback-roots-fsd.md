## Решения

- **Корней сколько угодно.** В коде число не было зашито: `layoutForest` оборачивает в
  виртуальный корень все корни, которые вернул селектор; селекторы и агрегаты считают
  корнем любой узел с `parentId: null`. «Пять» попало в журнал и план README из данных мока.
  Чтобы это было проверяемо, а не утверждением, добавлены тесты на разное число корней:
  корни в исходном порядке, `parentId: null`, `depth: 0`, `y: 0`, соседи через `siblingGap`,
  рёбер от виртуального корня нет, координаты нормализованы, bounds плотный. Скелетон
  по-прежнему рисует 4 плашки — это декорация, к данным не привязана.
- **Слой FSD — группа пакетов, пакет — функциональность.** README говорил «слои FSD —
  отдельные пакеты». Структура репозитория уже была правильной (`packages/<слой>/<пакет>`),
  неточной была формулировка. README переписан с таблицей «слой → пакеты-функциональности»;
  правило вынесено в CLAUDE.md, чтобы следующие шаги добавляли функциональность новым пакетом
  в слое.
- **Авторство.** Автор подтвердил, что руками ничего не писал. В README и в записи
  `review-fixes` снято утверждение, что раздел «Общее правило» в CLAUDE.md написан человеком:
  он и удаление «в том же коммите» появились вне этой сессии агента. Для всех записей журнала
  «Написано или переписано человеком: нет» теперь подтверждено автором.
