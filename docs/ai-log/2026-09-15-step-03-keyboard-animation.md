Проверка и доделка шага 03 части 4: клавиатурная навигация по таблице и анимация раскрытия дерева. Всё оказалось уже реализовано, обновление потребовалось только README.

## Что реализовано ранее

### Клавиатурная навигация по таблице

`useTableKeyboard` (`packages/entities/org-tree/src/model/useTableKeyboard.ts`, 195 строк) — полная реализация roving tabindex:

- Стрелки вверх/вниз, Home/End, PageUp/PageDown (размер страницы из `ResizeObserver`), Enter для выбора.
- Модификаторы (Alt/Ctrl/Meta/Shift) игнорируются.
- Фокус привязан к узлу (id), а не к позиции: смена сортировки сохраняет фокус, фильтр переносит на ближайшую оставшуюся строку.
- `useLayoutEffect` двигает DOM-фокус и вызывает `scrollIntoView({ block: 'nearest' })`.
- Клик по строке делает её табулируемой (`handleFocus`).

`OrgTableRow` — строка получает `tabIndex={focusable ? 0 : -1}`; кнопка названия — всегда `tabIndex=-1`, вне таб-порядка.

Тесты (`OrgTable.dom.test.tsx`, describe «клавиатура», 7 тестов) и мутации (`entities-table-keyboard` — 9, `entities-table-row-focus` — 2) покрывают все требования ТЗ.

### Анимация раскрытия дерева

`useLayoutTransition` (`packages/entities/org-tree/src/model/useLayoutTransition.ts`, 251 строка) — стейт-машина enter/exit:

- Новый узел — `data-motion="enter"`, исчезающий — `data-motion="exit"`.
- По `animationend` исчезающий узел удаляется из переходного состояния (`completeExit`).
- Быстрая серия раскрытий: вернувшийся до конца анимации узел восстанавливается (не накапливается).
- Первые данные — без анимации (нет прежней раскладки).

`TreeCanvas` — CSS `@keyframes` (`nodeEnter`, `nodeExit`, `edgeEnter`, `edgeExit`):

- Узлы проявляются/исчезают через `opacity` и `transform`.
- Тройная вложенность `<g>`: позиция в раскладке → смещение к якорю (родитель) → возврат с анимацией.
- Исчезающий узел: `data-node-id` снят (не ловит клики), `aria-hidden` (скрыт от скринридера).
- `@media (prefers-reduced-motion: reduce)` — `animation-duration: 0s`.

Тесты (`OrgTreeView.dom.test.tsx`, 10 тестов) и мутации (`entities-layout-transition` — 7, `entities-tree-motion` — 5, `entities-tree-edge-motion` — 1).

## Решения

**Клавиатура уже реализована, трогать не надо** → код написан в предыдущих сессиях и покрыт тестами и мутациями. Анимация тоже. Задача агента — убедиться и дописать README.

**Трактовка «height transition» зафиксирована в README** → ТЗ говорит «height transition», но дерево — SVG-холст без высоты DOM-элемента. Вместо этого анимируются `opacity` и `transform` (композитимые свойства) для появления/исчезновения узлов и рёбер. Это записано явно.

**Рёбра без `stroke-dasharray/dashoffset`** → реализованы через `opacity` (как и узлы). Дешевле, без перерисовки на каждый кадр. ТЗ допускало оба варианта, выбор сделан ранее.
