# ADR-006: Адресная строка — источник правды для фильтра, сортировки и режима

- Статус: принято
- Дата: 2026-09-15
- Источник: `docs/ai-log/2026-09-15-step-02-url-views.md`,
  `2026-09-16-step-04-ai-search-client.md`

## Контекст

Шаг 02: рядом с деревом — таблица с фильтром и серверной сортировкой, три режима просмотра
(дерево, таблица, оба). Ссылкой на экран нужно делиться: новая вкладка по скопированному адресу
открывает тот же режим, фильтр и сортировку. Кнопка «назад» должна вести себя предсказуемо.

Правила — ТЗ шага 02 (часть 3): URL как источник правды, replace и push, схлопывание режимов.

## Решение

- **В адресе — `q`, `sort`, `dir`, `view`**, с шага 04 — поля структурного фильтра (`levels`,
  `minHeadcount` и другие). `useOrgDashboardParams` читает их через `useSearchParams` на каждом
  рендере; в состоянии React они не дублируются.
- **Невалидное значение заменяется умолчанием** при чтении; адрес не переписывается, умолчания в
  него не пишутся. Посторонние параметры не трогаются.
- **Фильтр и сортировка — `replace`, режим — `push`.** «Назад» возвращает к прежнему режиму вместе
  с фильтром, какой был в нём.
- **Выделение и раскрытие в адрес не входят** — это состояние работы с экраном, живёт в состоянии
  React страницы.
- **Ширина ограничивает намерение:** уже 1280px `view=split` показывается как дерево, но в адресе
  остаётся `split`; на широком экране split возвращается.
- **Черновик поля поиска** — локальное состояние `useTableModel`, в `q` уходит после паузы 250 мс.

## Альтернативы

- **Параметры в Redux с синхронизацией в адрес.** Два источника правды и эффекты синхронизации в
  обе стороны.
- **Локальное состояние с записью в адрес эффектом.** Та же синхронизация; первый рендер по ссылке
  идёт с умолчаниями, затем перерисовывается.
- **`push` для всего.** «Назад» отматывал бы фильтр по символу, а серия сортировок забивала бы
  историю.
- **Выделение и раскрытие в адресе.** Раскрытие зависит от данных, которые между открытиями ссылки
  меняются; адрес разрастается состоянием, которым не делятся.

## Последствия

- Ссылка воспроизводит экран; структурный фильтр по ссылке применяется без вызова модели.
- Смена режима не делает запроса: параметры те же, ключ кеша тот же.
- Раскрытие и выделение сбрасываются при уходе со страницы.
- Адрес пишется от `searchParams` последнего рендера: смена режима в тот же рендер, где
  применяется только что отправленный `q`, запишет режим поверх адреса без этого `q`. Окно — один
  рендер; не воспроизводилось.
- Стрелки в переключателе режима добавляют запись истории на каждый шаг: у радиокнопок стрелка
  сразу выбирает, а смена режима — `push`.
