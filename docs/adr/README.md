# Архитектурные решения (ADR)

Нетривиальные решения проекта: контекст, решение, отброшенные альтернативы, последствия.
Файл — `NNN-название.md`, номер сквозной. Решение, которое пересмотрели, не переписывается:
новый ADR ссылается на старый, в старом меняется статус.

ADR написаны после реализации по журналу `docs/ai-log/` и коду; в строке «Источник» — записи
журнала, где решение принималось. Если альтернатива в журнале не рассматривалась, это сказано
прямо.
