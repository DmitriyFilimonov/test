Выявлены на ревью шага 01 (2026-09-15). Файл назван «step-03» по ожиданию того ревью;
UI дерева сделан в завершающей части шага 01 — см. `docs/ai-log/2026-09-15-step-01-tree-render.md`;
позже перенесён из `@widgets/org-tree` в `@entities/org-tree` (`docs/ai-log/2026-09-15-step-01-widget-to-entity.md`).

- [x] **Кнопка «Повторить» — `disabled`, пока идёт запрос.** В баннере ошибки поверх
      дерева (данные есть, ревалидация упала) — `disabled` при `status === 'loading'`.
      В полноэкранной ошибке (данных нет) после нажатия сразу показывается скелетон,
      кнопки на экране больше нет. → `2026-09-15-step-01-tree-render.md`
- [x] **Тест на `useQuerySubscription`.** Не сделан: jsdom и `@testing-library/react` в
      проект не пришли — клавиатурную навигацию, ради которой их планировали, пользователь
      исключил из объёма. Нужны: монтирование → `subscribed`, размонтирование →
      `unsubscribed`; быстрое размонтирование и монтирование «подписка → отписка → подписка» и итоговый счётчик 1.
      С шага 02 хук принимает `params`: переподписка (отписка от старого ключа, подписка на
      новый) при смене ключа и отсутствие переподписки при новом объекте с тем же ключом
      (`2026-09-15-step-02-multikey-cache.md`).
      Косвенно поведение проверено в браузере (`2026-09-15-step-01-tree-render.md`, «уход и возврат»).
      → `useQuerySubscription.dom.test.tsx` (проект vitest `dom`, jsdom); `2026-09-15-step-02-table-ui.md`
- [ ] **Запись в адрес по последнему отрисованному адресу.** `setSearchParams` строит адрес из
      `searchParams` рендера, навигация идёт в transition: смена режима в момент применения
      только что отправленного `q` может записаться без него. Не воспроизводилось; снимается
      чтением актуального адреса роутера при записи (`2026-09-15-step-02-url-views.md`).
- [ ] **Длинный Tab по дереву.** У каждой видимой карточки две кнопки (выбор и шеврон): в split
      до таблицы — десятки нажатий. Если вернётся клавиатурная навигация — roving tabindex по
      дереву (`2026-09-15-step-02-url-views.md`).
      Отложено: доступность вне объёма, приложение внутреннее (решение автора,
      `2026-09-15-step-02-grouped-table.md`).
